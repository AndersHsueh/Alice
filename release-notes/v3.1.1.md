### 1.2 重大架构变更

#### 🛰️ OTEL 本地 dashboard(IK8MWZ #18)

- **`src/services/analytics/aggregator.ts`**(~225 行):纯函数聚合器,读 `~/.alice/otel/trace.jsonl` → 每日 token + per-tool 错误率 + 7d × 24h 热力图
- **`src/services/analytics/analyticsRenderer.ts`**(~140 行):纯字符串 dashboard 渲染(ANSI / plain)
- 隐私边界在 aggregator 出口处强制 — `assertPrivacySafe` 深度遍历断言不含 prompt / completion / system_prompt / user_message / assistant_message 等敏感子串
- 损坏行跳过不崩(JSON.parse 失败 / 缺关键字段)
- 输出对象只含数值/枚举/字符串,绝不复制 LLM 内容

#### 🤝 多 worker 协作(IK8MWV #14)

- **teamMessageBus**(`src/runtime/agent/coordinator/teamMessageBus.ts`):纯逻辑内存消息总线,sequence 单调 + ack 语义 + 重投 1 次 + warn-and-continue
- **teamMessage builtin tool**(`src/tools/builtin/teamMessage.ts`):AliceTool 定义,send/recv/ack 三 action;主对话直接调 → success:false(未在 spawn worker 上下文)
- **executor / reviewer profile 实装**(`src/runtime/agent/coordinator/{executorRunner,reviewerRunner}.ts`):原 7 profile 中 4 个 spawnable(consultant / executor / researcher / reviewer)
- **concurrentAgentRunner 多 worker 共享总线**:`runAgents` 新增 `teamMessageBus` 选项,spec done 后 yield `team_message_batch` 事件
- **workspace per-session 串行锁**(`src/runtime/agent/coordinator/workspaceCoordinator.ts`):chain-based FIFO 锁 + 跨 workspace 并发 + 失败自动释放 + 超时抛错

#### 🎙️ Voice 输入(IK8MWX #16)

- **`src/voice/`**:6 个文件(types / nullEngine / voiceInput / whisperEngine / voiceProcessor / wakeWordEngine + index),源码层 ~32KB
- **whisper.cpp 子进程 ASR**:`WhisperCppEngine` 通过 `child_process.spawn` 调 whisper.cpp CLI,写 PCM 到 tmp file → 解析 stdout;binary 缺失 / 超时 / 退出码非 0 抛 `AsrError`
- **VoiceProcessor 抽象层**:基类 + NullVoiceProcessor / RealVoiceProcessor(依赖注入 capture/asr/wakeWord);`getVoiceProcessor(voiceMode?)` factory 读 `feature('voice_mode', false)`
- **EnergyWakeWordDetector**:基于 RMS 能量阈值的 wake word 检测(prototype)
- **processUserInput(buffer)** 统一 voice/text 入口
- WakeWordDetector 接口 batch API 对齐(原 streaming 接口修正)

#### 🧩 Plugin Marketplace(IK8MWY #17)

- **`src/plugin/`**:5 个文件(types / manifest / registry / sandbox / marketplace / loader + index)
- **manifest Zod v4 schema**:`validateManifest` / `tryValidateManifest` 拒绝 8+ 畸形 manifest + 字段级 issues(path / message / code)
- **PluginRegistry**:install / uninstall / get / list / has / setStatus;`scanPluginDir` 扫 `~/.alice/plugins/<plugin>/manifest.json`,broken plugin 也被发现
- **PluginSandbox**(`src/plugin/sandbox.ts`):`vm.runInNewContext` 求值 + require 白名单拦截 + process.env Proxy 拦截(get/has 双路径)+ per-plugin / per-session tool quota
- **Marketplace + 签名校验**:`signManifest` / `verifySignature`(HMAC-SHA256 模拟 GPG);`Marketplace.installFromManifestJson` 签名失败拒装 + 长度不匹配拒装;crypto.timingSafeEqual 防时序攻击
- **PluginLoader**:load / unload / invoke(走 sandbox.invokeTool quota 隔离)+ `loadPluginSampleWeather()` 端到端 fixture

### 1.3 工程治理

- **测试基线**:`test-case/` 目录共 27 个测试脚本,1173 断言全绿(v3.1.0 的 608 + P2 新增 565)
- **`test-list.md` 索引**:每条测试脚本回填 issue 编号 + 对应 PR
- **DCE 友好**:新增 `src/voice/**`(~32KB)+ `src/plugin/**`(~30KB)在对应 flag 关闭时被 `buildTimeDCE`(#4)剪除
- **全量回归**:27 套测试 / 1173 断言 PASS / 0 FAIL;`bun build.ts` 成功

## 四、已知问题与限制

### 4.1 v3.1.0 遗留限制(本 release 未触及)

- **`src/shim/qwen-code-core.ts` 死代码层**:`canUseRipgrep()` 硬编码 `return false`、`getLastPromptTokenCount()` 硬编码 `return 0`,在 v3.0.1 已存在但未被消费
- **TeamMemorySync 远程 endpoint 未实装**:v3.1.0 仅协议 + 本地 mock;远程 endpoint(`POST /v1/teams/{teamId}/memories:push` + `GET :pull`)为 v4.0.0 预留
- **3 个 builtin tool 暴露风险**:`#20 wiki-ingest` 与 `#21 wiki-lint` 是 builtin skill(在 `~/.alice/skills/builtin/`),与 user skill 优先级冲突时 builtin 优先
- **3 个 AgentProfile 未实装**:`coder` / `writer` / `security` / `tester` 在 spawn 时会报明确"未实装"错误(本 release 把 `coder` 重命名为 `executor` 并实装,所以剩 3 个)

### 4.2 v3.1.1 新增限制

- **EnergyWakeWord 是 prototype**:基于 RMS 能量阈值(简单可靠),不依赖 snowboy / openWakeWord 模型;后续 PR 可替换为真 wake word 模型
- **HMAC-SHA256 模拟 GPG**:后续 PR 可替换为真 GPG / openpgp 实现(verifySignature 抽象已留)
- **`vm.runInNewContext` 简化沙箱**:不实装真 V8 isolate(需要 vm2 / isolated-vm)— 用 vm module 简化,足够覆盖 #17 ② ③ 的核心断言
- **voice_mode flag 默认关闭**:依赖用户在 `~/.alice/settings.jsonc` 显式启用 `voice_mode: true` 才走 RealVoiceProcessor
- **Plugin Sandbox 不真 require plugin code**:本 PR 提供 tool 注入接口 + 端到端 demo;真 require 拦截留给后续 PR

## 五、迁移指南

### 5.1 从 v3.1.0 升级

```bash
git fetch origin
git checkout v3.1.1

```

### 5.2 行为变化

- **多 worker 并发**:使用 `runAgents(specs, deps, { teamMessageBus })` 启用跨 worker 通信;不传 bus 时行为不变(向后兼容)
- **Voice 入口**:使用 `import { getVoiceProcessor } from '@/voice/index.js'` 拿到 VoiceProcessor 实例;voice_mode flag 关闭时返 NullVoiceProcessor(无副作用)
- **Plugin 安装**:使用 `new Marketplace({ signingKey }).installFromManifestJson(json, sig, path)`;签名校验失败抛 `SignatureVerifyError`,不污染 registry
- **OTEL dashboard**:使用 `import { aggregateFromFile, renderDashboard } from '@/services/analytics'` 读取 `~/.alice/otel/trace.jsonl` 渲染 dashboard

### 5.3 新 API 速查

```typescript
// OTEL dashboard
import { aggregateFromFile, renderDashboard } from '@/services/analytics';
const result = aggregateFromFile('~/.alice/otel/trace.jsonl');
const dashboard = renderDashboard(result, 'plain'); // 或 'ansi'

// 多 worker 协作
import { runAgents } from '@/runtime/agent/concurrentAgentRunner';
import { TeamMessageBus } from '@/runtime/agent/coordinator/teamMessageBus';
const bus = new TeamMessageBus();
for await (const ev of runAgents(specs, deps, { teamMessageBus: bus })) {
  if (ev.type === 'team_message_batch') console.log(ev.messages);
}

// Voice
import { getVoiceProcessor } from '@/voice/index.js';
const vp = getVoiceProcessor(); // 读 voice_mode flag
const result = await vp.process({ kind: 'text', content: 'hi', capturedAt: 0 });

// Plugin
import { Marketplace, PluginLoader, loadPluginSampleWeather } from '@/plugin/index.js';
const mp = new Marketplace({ signingKey: process.env.PLUGIN_KEY });
const loader = new PluginLoader(mp.getRegistry());
const { pluginName, manifest, impls } = loadPluginSampleWeather();
const sig = signManifest(JSON.stringify(manifest), process.env.PLUGIN_KEY);
mp.installFromManifestJson(JSON.stringify(manifest), sig, '/path/to/plugin');
loader.load(pluginName, impls);
const weather = await loader.invoke(pluginName, 'get_weather', '北京');
```
