# v3.1.2 Release Notes

> 发布日期：2026-08-16
>
> 发布类型：可信赖性补丁发布
>
> 版本标签：`v3.1.2`

## 一、发布摘要

v3.1.2 的目标不是继续堆叠能力，而是兑现一句产品承诺：**从能力集合走向可信赖的 Code Agent 产品。**

本版本把 v3.1.1 已具备的 Analytics、Multi-Agent Team、Voice 与 Plugin 能力接入真实入口，补齐取消、超时、权限、会话与发布验证链路，并让测试入口收口为可复现的统一 gate。

## 二、用户可见变化

### Analytics

- 新增 `/analytics`，并保留 `/otel` 别名。
- 本地 OTEL JSONL 改为 async streaming 聚合，支持 `AbortSignal`、`maxBytes` 与 `maxLines`。
- 不再构造完整 spans 数组，超限或取消时给出明确结果。

### Multi-Agent Team

- 新增 `/team` 稳定入口，执行 staged orchestrator-relay：consultant 与 researcher 并发，结果写入 bus/workspace artifact，再交由 executor 规划并由 reviewer 审阅。
- 明确产品边界：当前由 orchestrator 代 relay，worker 尚未通过 tool-call 直接互聊；executor 输出执行计划，不直接修改用户文件。
- worker 默认 120 秒超时；超时、外部取消和客户端断连会终止 active worker，并阻止后续阶段误启动。

### Local Plugin

- 新增 `/plugins discover/install/list/invoke/uninstall` 本地声明式插件入口。
- HMAC 签名校验、权限 `allow`/`deny`/`ask`、每插件/每会话 quota 均在真实 invoke 路径生效；无授权上下文时 `ask` 默认拒绝。
- 并发安装使用唯一 staging 与目标锁，避免目标被其他失败安装回滚。
- `/clear` 与恢复会话会重置同一生产 plugin session quota。
- 当前仍是本地插件闭环，不是远程 marketplace 或身份认证系统。

### Voice

- 新增 `/voice status/start/stop`。
- 缺少录音生命周期或运行依赖时明确降级，不会伪报启动成功。
- feature flag 默认读取 `~/.alice/feature_flags.jsonc`，也可由 `ALICE_FEATURE_VOICE_MODE` 覆盖。

## 三、可靠性与安全修复

- `AbortSignal` 从 daemon 请求贯穿 agent loop、Team profiles、LLMClient 与各 provider；主模型已取消时不会再启动 fallback。
- HTTP 与 Unix Socket 客户端断连均能取消 Team 和普通 LLM stream。
- Unix Socket HTTP framing 会等待完整 `Content-Length` body，并限制 header 为 64 KiB、body 为 16 MiB；拒绝无效或冲突的长度。
- 测试 runner 为每个脚本设置默认 120 秒上限；POSIX 下以进程组执行 `SIGTERM → 75ms grace → SIGKILL`，覆盖父进程先退出而孙进程忽略信号的情况。
- 测试不再删除或写入真实 `~/.alice` 数据；core preflight 会阻断已知 HOME 派生路径进入破坏性文件操作。
- Plugin 输出统一剥离 ANSI/C0/C1 控制字符，权限检查发生在插件代码装载与执行之前。

## 四、工程入口

```bash
bun run typecheck
bun run test:core
bun run verify
```

`bun run verify` 是发布前唯一推荐入口，依次执行类型检查、HOME I/O 安全预检、核心测试、最终构建、release smoke 与 release contracts。发布合同只接受本轮随机 nonce marker 对应的构建产物，避免把陈旧 `dist` 误认为当前发布。

## 六、升级方式

```bash
git fetch --tags origin
git checkout v3.1.2
bun install
bun run verify
```

本版本没有新增第三方依赖。

## 七、仍未承诺的能力

- Team worker 通过 tool-call 直接互聊与自动修改文件。
- Voice 平台录音生命周期的完整产品化。
- Plugin 远程市场、远程下载与身份认证。
- Windows 对已孤儿化进程树的 POSIX 等价强保证；Windows runner 采用 `taskkill /T`、grace 后 `/T /F` 的 best-effort 清理。

这些边界会继续保留在文档与测试中，不以“组件存在”冒充“产品闭环”。
